# Monty Bytecode Interpreter (Learning Copy)

A C interpreter project for Monty bytecode, including opcode handlers and list operations.

## Technologies and topics

C, stacks, queues, linked lists.

## Getting started

Inspect `main.c` and `monty.h` to understand accepted bytecode and build requirements.

## Repository organization

Browse the source files and topic directories for individual examples. Some exercises are standalone and should not be compiled together.

## Technical interview discussion

Parser robustness, stack underflow, opcode dispatch, and memory ownership.

## Scope

Educational coursework and practice code. This repository is not claimed to be production-ready or security-audited.
